# badwords.txt
# Blocklist fuer automatische Moderation von Benutzernamen und Raumnamen.
#
# Quellen (recherchiert, nicht frei erfunden):
#   - LDNOOBW "List of Dirty, Naughty, Obscene, and Otherwise Bad Words"
#     https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words
#     (Listen "de" und "en")
#   - dsojevic/profanity-list (englische Liste mit Tags severity/racial/religious)
#     https://github.com/dsojevic/profanity-list
#   - Wikipedia "List of religious slurs"
#     https://en.wikipedia.org/wiki/List_of_religious_slurs
#   - Deutsche NS-/Volksverhetzungs-Begriffe: allgemein bekannte, in
#     Deutschland/Oesterreich rechtlich relevante Begriffe (§86a, §130 StGB)
# Aus jeder Quelle wurde nur eine kuratierte Teilmenge uebernommen: neutrale/
# mehrdeutige Woerter (z.B. reine Koerperteile, Eigennamen, Trinkbezeichnungen)
# wurden bewusst weggelassen, damit die Liste gezielt Beleidigungen/Hassrede
# trifft statt normale Namen faelschlich zu sperren.
#
# Format: eine Phrase pro Zeile, Kleinschreibung, keine Sonderzeichen.
# Empfohlene Anwendung:
#   1. Eingabe normalisieren: lowercase, Umlaute/Diakritika transliterieren
#      (ae/oe/ue/ss), Leetspeak-Ersetzungen (0->o, 1->i/l, 3->e, 4->a, 5->s,
#      7->t, @->a, $->s), Trennzeichen (_, -, ., Leerzeichen) entfernen.
#   2. Auf Teilstring-Treffer pruefen (nicht nur exakte Gleichheit), da
#      Benutzer Praefixe/Suffixe anhaengen (z.B. "xX...Xx", Zahlen).
#   3. Kurze/mehrdeutige Eintraege (<=5 Zeichen, z.B. "kraut", "fick") nur
#      mit Wortgrenzen pruefen, um False Positives bei harmlosen Namen wie
#      "Sauerkraut" oder "Frick" zu vermeiden.
#   4. Diese Liste ist bewusst NICHT erschoepfend gehalten (keine reinen
#      Zahlencodes, keine allgemeinen religioesen/ethnischen Eigennamen ohne
#      beleidigenden Kontext). Sie sollte um Meldungen/Reports aus der
#      eigenen Nutzerbasis ergaenzt werden statt versucht zu werden,
#      "vollstaendig" zu sein.
